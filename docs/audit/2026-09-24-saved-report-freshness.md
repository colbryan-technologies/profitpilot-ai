# Saved reports and AI context checkpoint

Order lists now check readiness for the complete date span on the displayed page, and withhold cached contribution and COGS coverage if it is not ready. Cached values also require the current calculation version and a calculation timestamp at least as recent as the order's Shopify update timestamp. Order detail checks its local calendar day before computing from current stored inputs. Gaps between sparse listed orders conservatively block that page's cached values; no stored orders are removed.

Saved briefings are checked against readiness for their reporting/comparison days, calculation version, and newer daily snapshot calculations. Outdated text is withheld at the loader boundary and replaced with a refresh/data-health explanation. Regeneration replaces the same week's record and timestamps it at generation start, allowing recalculations during generation to invalidate it later. Reports includes a refresh action for the current week; old archived periods do not yet have on-demand regeneration. Snapshot recalculation with identical numbers can conservatively invalidate a briefing.

AI follow-up context now includes only complete question/answer pairs whose stored grounding exactly matches the current report data. Comparison ignores JSON object-key order. Changed figures, periods, versions, missing legacy grounding and unmatched questions are omitted; the current question is still sent normally. Previously stored messages are not deleted by this change. This reduces stale or out-of-history figures being reintroduced through context, but does not replace provider-output grounding validation or retention work.

Readiness checks remain point-in-time checks, not a transaction spanning rendering or external AI calls. Concurrent writes, live browser review, and query costs for multiple archived briefings still require production acceptance/performance checks. This checkpoint changes internal access and presentation, not Shopify API queries. No production deployment or App Store submission occurred.
